# iguazu-types

![GitHub License](https://img.shields.io/github/license/LFDT-Iguazu/iguazu-types)
[![OpenSSF Scorecard](https://api.scorecard.dev/projects/github.com/LFDT-Iguazu/iguazu-types/badge)](https://scorecard.dev/viewer/?uri=github.com/LFDT-Iguazu/iguazu-types)
[![OpenSSF Best Practices](https://www.bestpractices.dev/projects/16196/badge)](https://www.bestpractices.dev/projects/16196)

`iguazu-types` is a Go module that provides shared protocol types and minimal utilities for Iguazu components (e.g. `iguazu-engine` / `iguazu-consensus`).

Go module path: see `go.mod`.

## Releases

Releases are published as [GitHub Releases](https://github.com/LFDT-Iguazu/iguazu-types/releases) with signed provenance;
see [RELEASE.md](RELEASE.md) for the process and how to verify them, and [CHANGELOG.md](CHANGELOG.md)
for the changes. Use the module with:

```shell
go get github.com/LFDT-Iguazu/iguazu-types@latest
```

## Documentation

API documentation is available on [pkg.go.dev](https://pkg.go.dev/github.com/LFDT-Iguazu/iguazu-types).
